# 2. ĐẶC TẢ KỸ THUẬT BUILD FRONTEND REACT + SHADCN/UI

## 2.1. Cấu hình `package.json` và Build Scripts
Hãy viết đầy đủ file `frontend/package.json` bao gồm:
- **Core React & Build:** `react`, `react-dom`, `vite`, `@vitejs/plugin-react`, `typescript`.
- **Bộ thư viện chuẩn của `shadcn/ui`:** `clsx`, `tailwind-merge`, `class-variance-authority`, `lucide-react`, `tailwindcss-animate`, `@radix-ui/react-slot`, `@radix-ui/react-slider`, `@radix-ui/react-tooltip`, `@radix-ui/react-tabs`, `@radix-ui/react-separator`.
- **Bộ thư viện 3D LiDAR:** `three`, `@types/three`, `@react-three/fiber`, `@react-three/drei`.
- **Scripts:** `"dev": "vite"`, `"build": "tsc && vite build"`, `"preview": "vite preview"`.

## 2.2. Cấu hình Path Alias (`@/*`) và `lib/utils.ts` cho `shadcn/ui`
1. Trong `vite.config.ts` và `tsconfig.json`: Cấu hình alias `@` trỏ về `./src` để mọi lệnh `import { Button } from "@/components/ui/button"` chạy không lỗi khi chạy `npm run build`.
2. Trong `src/lib/utils.ts`: Viết hàm chuẩn của shadcn:
   ```ts
   import { type ClassValue, clsx } from "clsx"
   import { twMerge } from "tailwind-merge"
   export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)) }
   ```
3. Viết đầy đủ mã nguồn cho các file trong `src/components/ui/` (`button.tsx`, `card.tsx`, `badge.tsx`, `slider.tsx`, `tooltip.tsx`, `separator.tsx`) để dự án chạy độc lập ngay lập tức sau khi `npm install` mà không bị thiếu file.

# 3. ĐẶC TẢ KỸ THUẬT BACKEND FASTAPI & THUẬT TOÁN M45 (`backend/`)
1. **Giao tiếp CVAT Local (`http://localhost:8080`):**
   - Lấy danh sách hộp 3D (`GET /api/tasks/{id}/annotations`), lấy đám mây điểm (`GET /api/jobs/{id}/data`).
   - Đồng bộ ngược 2 chiều: Tạo Issue cảnh báo trên CVAT (`POST /api/issues`) và cập nhật trạng thái hộp (`PATCH /api/jobs/{id}/annotations`).
2. **Thuật toán Kiểm định Tự động (`m45_engine.py` bằng NumPy):**
   - Tính khoảng cách $D(r) = \sqrt{x^2 + y^2 + z^2}$ và mật độ tia.
   - Phát hiện suy biến ma trận hiệp phương sai PCA ($h < 0.05\text{m}$).
   - Phát hiện lỗi cắt nhầm điểm mặt đường `z-cutoff` ($N_{raw} \gg N_{filtered}$).
   - Kiểm tra ranh giới phanh an toàn SOTIF ISO 21448.
3. **Chế độ Zero-Config Demo:** Nếu CVAT Local chưa bật ở port 8080, tự động sinh dữ liệu đám mây điểm LiDAR vòng sóng và các hộp 3D mẫu để Frontend hiển thị và tương tác được ngay.
